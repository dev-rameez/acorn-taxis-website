# Elementor Site Settings — Acorn Taxis

Apply in **Elementor → Site Settings**.

## Global colours

| Name | Hex | Use |
|------|-----|-----|
| Navy | `#0B1F3A` | Header, primary text accents, dark bands |
| Navy Deep | `#071627` | Footer, sticky bar background |
| Gold | `#C4A35A` | Primary buttons, accents, underlines |
| Gold Soft | `#D4B875` | Hover states |
| Off White | `#F7F5F1` | Page backgrounds, alternating sections |
| Surface | `#FFFFFF` | Cards, header (if light), content boxes |
| Charcoal | `#1C1C1C` | Body text |
| Muted | `#5C6570` | Secondary text |
| Border | `#E4DFD6` | Dividers, light borders |

**Avoid:** bright yellow from the old site, neon accents, purple SaaS gradients.

## Global fonts

| Role | Suggested font | Fallback |
|------|----------------|----------|
| Primary (headings) | `DM Sans` | system-ui, sans-serif |
| Secondary (body) | `Source Sans 3` | Georgia, serif optional for legal only |

Weights: headings 600–700; body 400–500.

### Typography scale (desktop → mobile)

| Style | Desktop | Mobile |
|-------|---------|--------|
| H1 | 40–44px | 30–32px |
| H2 | 28–32px | 24px |
| H3 | 22px | 20px |
| Body | 18px | 16–17px |
| Small | 14–15px | 14px |

Line height body: ~1.6. Section max width: **1140px**.

## Buttons

### Primary — Book Online
- Background: Gold `#C4A35A`
- Text: Navy `#0B1F3A`
- Hover: Gold Soft `#D4B875`
- Padding: 14px 28px
- Border radius: 4px (not pill)
- Link: Cab9 booker, open in new tab
- Min height: 48px (touch-friendly)

### Secondary — Call Now
- Background: transparent or white
- Border: 2px solid Navy
- Text: Navy
- Hover: Navy fill, white text
- Link: `tel:+44182763333`

### Ghost on dark
- Border/text: white or gold
- Used on navy bands / sticky bar

## Spacing rhythm

- Section padding: 64px desktop / 40px mobile (vertical)
- Gap between title and body: 12–16px
- Gap before CTAs: 24px
- Avoid large empty hero whitespace
